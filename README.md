# Информационная база для салона красоты

## Описание проекта
Информационная база (ИБ) предназначена для автоматизации учета и внутренних бизнес-процессов салона красоты. Проект изначально спроектирован и разработан на базе Библиотеки стандартных подсистем (БСП), что обеспечивает надежную архитектуру и соответствует современным стандартам разработки на платформе 1С.

В рамках проекта реализован полный цикл работ: от проектирования структуры метаданных до оформления фирменного стиля интерфейса.

## Реализованный функционал
В ходе разработки были созданы и настроены следующие элементы конфигурации:
- **Справочники и документы:** разработана структура для хранения и обработки данных, необходимая для работы салона.
- **Регистры:** настроены регистры для накопления и систематизации информации.
- **Перечисления и права:** созданы необходимые перечисления, настроены роли и права доступа пользователей.
- **Отчеты и обработки:** разработаны механизмы для формирования отчетности и выполнения сервисных задач.
- **Интерфейс:** настроен фирменный стиль, обеспечивающий удобство и эстетичный внешний вид рабочего места.

## Стек технологий
- **Платформа:** 1С:Предприятие 8.3 
- **Библиотека:** БСП (Библиотека стандартных подсистем)
- **Языки:** Встроенный язык 1С, язык запросов 1С

## Выводы и результаты
Проект позволил на практике закрепить навыки разработки «с нуля» на базе БСП. Освоено проектирование сложных структур метаданных, настройка прав доступа и кастомизация интерфейса под требования конкретного бизнеса. 

## ⚠️ Примечание к репозиторию
В данном репозитории для демонстрации навыков **опубликована только часть исходного кода и структуры метаданных** (ключевые модули, справочники, документы и отчеты). Полная конфигурация базы данных не выгружалась в целях оптимизации размера репозитория. Опубликованная часть дает полное представление о логике работы, архитектуре и стиле написания кода.
В силу того, что к сообществу програмистов я присоединилась совсем недавно, я безусловно могу допустить ошибки выгрузке файлов - выгрузить  что-то лишнее или не догрузить что-либо важное, за что заранее извиняюсь, прошу "понять и простить".

## Инструкция по развёртыванию
Для развертывания информационной базы необходимо:
1. Установить платформу 1С:Предприятие 8.3.
2. Открыть Конфигуратор.
3. В меню выбрать **«Конфигурация» -> «Загрузить конфигурацию из файлов»**.
4. Указать путь к папке с выгруженными файлами (находящейся в данном репозитории).
5. Выполнить обновление конфигурации базы данных (F7).

**Системные требования:** Windows, установленная платформа 1С:Предприятие 8.3, СУБД (например, файловый режим или MS SQL/PostgreSQL).
